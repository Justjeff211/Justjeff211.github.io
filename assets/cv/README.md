## ATS-friendly CV tips
- Single column, no tables, no text boxes, no graphics/icons.
- Standard section headings: Summary, Experience, Skills, Certifications, Education.
- Save as a real text-based PDF (not a scanned image).
- Match keywords from the job description you're applying to (e.g. "SOC Analyst",
  "Azure Security", "Incident Response", "SIEM", "KQL").
